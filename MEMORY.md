# MEMORY.md — Действующие решения

> Читается в каждой сессии. Только действующие правила, по строке, со ссылкой на файл, где правило записано полностью.

## Процесс
- **Один эпизод — один чат; один стоп Nurlan — угол подачи** (вместе с черновиком упаковки). После «да» — до файлов для VideoEditor без вопросов. → `production/new-episode.md`
- **Сценарий сразу на английском.** Нейронность снимают Homer · Nolan · Amed · `humanizer` переплетёнными проходами до сохранения final. → фаза 3
- **Claude сам сохраняет** `en-script-v1.txt` (снимок, не меняется) = `en-script-final.txt`. Nurlan правит final при желании → Claude проверяет, пересобирает файлы для озвучки и повторяет разбор v1 → final.
- **История канала пишется сразу после передачи в VideoEditor** (`ep-NN.md`, `INDEX.md`, строка `CHANGELOG.md`, разбор v1 → final, уроки) — в той же сессии, не дожидаясь монтажа и публикации: эпизод может закрыться без фазы 8. → фаза 5
- **Разведку делает hl-script сам:** карточка темы — сырьё; Homer собирает много фактов по первоисточникам и смотрит поле на YouTube по ключевым словам темы (vidIQ, не только наши конкуренты); цитаты — только после сверки с оригиналом. Интересные каналы → `channel/competitors/candidates/`. → фаза 1
- **Помощники разгружают Nurlan:** проверки закрывают сами, в чат — суть в 3–6 строк, вопросы только по выбору и вкусу. Промежуточных версий не плодят. → `CLAUDE.md`, «Помощники»
- **Озвучка, кадры, монтаж — VideoEditor_2.0;** упаковка — Video-Wrapper. В «Осталось» hl-script их не пишет.
- **Файлы для смежных проектов** — только содержание: без статусов «ещё нет» и служебных пометок.
- **Таймкоды — у VideoEditor** (`06_montage\work\transcript.json`, `plan.json`); свой Whisper не запускаем.
- **Канон VO — запись.** Если в дубле изменились слова — правится `en-script-final.txt`. Расхождения распознавания по умолчанию — ошибки распознавания.
- **Коммит и push — только Nurlan;** не предлагать. В Claude Code файлы правятся напрямую; в веб-чате — текст блоком.

## Темы
- **Темы — из доказанного спроса,** не из головы: конкуренты (мастодонты и ориентиры) → банк популярных тем → наш угол → очередь. → `production/topic-search.md`, `channel/competitors/`
- **Хайп-эпизод** — еженедельный скан выбросов у конкурентов; встаёт следующим номером, очередь сдвигается; проверки Homer не сокращаются.
- **Карточка темы** после передачи эпизода в VideoEditor переезжает в `episodes/completed/`, строка — из очереди.

## Тема и упаковка
- **Железный закон:** зазор + механика обмана + голос Arny + масштаб. Стержень — механизм, не страна и не эпоха; ключи `cold war …` — только в резерве. **Маркер сползания** — два эпизода подряд из одного пласта. → `channel/niche.md`, `channel/keywords.md`
- **Упаковка формулируется до сценария:** ворота А и Б. **Заголовок проигрывает фактам.** → `CLAUDE.md`, «Упаковка»
- **Названия — интригующие:** парадокс или вопрос, ответ не угадывается, без хвостов `| место, год`. → `channel/keywords.md`
- **Обложка — ч/б фотоколлаж.** → `channel/style/branding.md`, раздел 05
- **«Чего нельзя обещать» — только в `brief.md`,** раздел «Упаковка». → `production/new-episode.md`, фазы 1–2

## Сценарий
- **28–33 мин, ~4 450–5 300 слов EN** (ориентир ~4 800, ≈160 на минуту видео). Длину на эпизод может задать Nurlan. Режем только воду. → `channel/style/beats.md`
- **Вкус Nurlan** — читать до черновика. → `channel/style/script-preferences.md`
- **Хук не называет эпоху** и не спойлерит развязку. → `channel/style/entry.md`, `beats.md`
- **Arny:** без портовой биографии и метафор; нью-йоркская речь — 1–2 штриха на такт. → `channel/staff/arny.md`, `amed.md`
- **Точность к документам:** криптоним ≠ народное имя, цитата — с говорящим и контекстом, неподтверждённое не утверждаем. → `channel/staff/homer.md`
- **Каждая идея — один раз;** якоря и переклички — в свежей формулировке. → `amed.md`, `beats.md`
- **Сценарии — только `.txt`,** в файле только текст и заголовки тактов (`BEAT 1. HOOK`…).
