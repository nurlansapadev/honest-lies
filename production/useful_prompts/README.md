# useful_prompts/ — Рабочие промпты

> Готовые к копипасте промпты, которые используются из раза в раз.
> Правила, из которых они выведены, живут в `channel/style/branding.md` —
> здесь только исполнение. При конфликте побеждает `branding.md`.

---

## `source-regenerate.txt` — перевод фото в гравюру

Четыре варианта строки под тип объекта: **человек / автомобиль / местность / предмет**.
Каждый вариант = каноническая строка гравюры (`channel/style/gravura.md`) плюс блок
сохранения анатомии, геометрии и перспективы исходного фото.

**Когда:** шот со `source: GENERATE`, у которого есть реальный референс, который надо
перерисовать, а не выдумать заново.
**Где исполняется:** GPT (по опыту делает точнее Nano Banana на перерисовке с референса).
**Обязательно приложить фото-исходник.**

Основание в бренде: `branding.md`, раздел 01 (гравюра — язык кадров внутри эпизода).

---

## `thumbnail-prompt.txt` — обложка эпизода в два шага

Шаг 1 — картинка в Nano Banana, шаг 2 — текст поверх ставится вручную.
Файл содержит мета-промпт: его отдают Claude, чтобы получить 5 **разных идей**
обложки (не вариантов одной), каждая — самодостаточным английским промптом.

**Что подставить:** заголовок ролика · тема эпизода (2–3 предложения, где зазор) ·
эпоха и место · текст, который ляжет сверху (3–4 слова).
**Референсы:** прикладываются картинками, они только для анализа композиции —
в готовых промптах отсылок на них быть не должно.

Основание в бренде: `branding.md`, **раздел 05 «Обложки»** — стиль, композиция,
запреты и чек-лист «уменьшить до 120 px». Обложка **не** гравюра.
