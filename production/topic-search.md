# topic-search.md — Поиск тем

> Откуда берутся эпизоды. Два потока: **плановый** (контент-план на 10–20 эпизодов вперёд) и **хайп** (быстрый эпизод вне очереди).
> Конкуренты — `channel/competitors/`. План — `episodes/content-plan.md`. Дальше любая тема идёт по `production/new-episode.md` с фазы 0.

## Ритм

| Что | Когда | Кто |
|---|---|---|
| Обновить список конкурентов (начиная с `channel/competitors/candidates/`) | раз в месяц | Claude ищет, Nurlan отсеивает |
| Пополнить банк популярных тем | раз в месяц, вместе со списком | Claude |

| Скан хайпа | раз в неделю | Claude по команде «скан хайпа» |

Команды Nurlan: **«обнови конкурентов»**, **«пополни контент-план»**, **«скан хайпа»**.

## Поток 1 — плановый контент-план

1. **Банк тем.** По каждому каналу из `channel/competitors/list.md` — топ-10 роликов за всё время (10 каналов → 100 тем) и выбросы за последний год (Nexlev `youtube_channel_videos` с сортировкой `popular` — бесплатно и сразу по 30 роликов; vidIQ `vidiq_outliers` — для года). Каждая строка — в `channel/competitors/popular-topics.md` со статусом: `новая` с нашим зазором или `не наша` с причиной в одну строку.
2. **Список кандидатов.** Из строк `новая`, без дублей (одна тема у двух каналов = одна строка, спрос суммируется) и без тем, на которые уже есть карточка в `episodes/next-idea-cards/`: файл `episodes/content-candidates/ДД-ММ/content-candidates-ДД-ММ.md`. Формат — как в `content-plan.md` (страна · зазор · шаблон · пласт · заголовок-гипотеза) + колонка «Спрос». Темы без понятного героя или зазора — отдельной таблицей «уточнить на разведке». Явные «нет» по фильтру вкуса (`channel/niche.md`) отсекаются ещё здесь.
3. **Разбор с Nurlan — по одному.** Claude пишет: кандидат N, суть в 6–10 строк, зазор (официальная версия → правда), шаблон, пласт, момент вскрытия, чем подходит по фильтру вкуса и чем рискованно. Nurlan отвечает «берём / не берём» и почему. Причина сразу учитывается в следующих кандидатах: слабые по новому правилу Claude не предлагает, а называет одной строкой «пропускаю — почему». Каждое решение с причиной — в таблицу «Решения Nurlan» внизу файла кандидатов; новое правило вкуса — в `channel/niche.md`.
4. **Карточка темы** — сразу после «берём», в ту же папку `content-candidates/ДД-ММ/`, с номером по порядку: `NN-<Тема>.md` (формат — как у карточек в `next-idea-cards/`): одна строка, паспорт, зазор, хребет на Homer, «Почему тема взята» словами Nurlan, черновое название, риски (хук без эпохи, пересечения с другими темами и эпизодами).
5. **В план.** Nurlan говорит, сколько мест освободить. Claude предлагает темы по фильтру вкуса и соседям: чередовать пласты (маркер сползания), не ставить подряд один шаблон или одну страну, сезонные — к своей дате, сильнейшие по спросу — ближе к началу. После «да» — строка в `episodes/content-plan.md` с ✅, карточка переезжает в `episodes/next-idea-cards/` без номера. Остальные карточки ждут в папке кандидатов — из неё план пополняется постепенно. Старые темы, которые сдвинуты, — в конец очереди, не удаляются.

## Поток 2 — хайп-эпизод

**Где ищем:** по каналам из списка конкурентов — ролики за последние 7 дней с аномальными просмотрами (vidIQ: `vidiq_outliers`, `vidiq_trending_videos`, сортировка popular + last week); плюс новости, которые оживили старую историю (рассекречивание, годовщина, фильм, суд).

**Тема — хайп, если все «да»:**
- ролик-выброс свежий (≤ 7–14 дней) и всё ещё набирает;
- проходит железный закон и у нас есть свой угол;
- не повтор пройденного;
- успеваем выпустить, пока волна жива — ориентир 5–7 дней от решения до публикации.

**Как встаёт в очередь:**
- Получает **следующий номер EP**, плановые сдвигаются на одну позицию.
- Удочку уже записанного эпизода не переделываем. Если она обещала плановую тему — хайп выходит между ними, а удочка самого хайп-эпизода ведёт к обещанной теме.
- Производство — тот же воркфлоу (`new-episode.md`), без сокращения проверок Homer. Ускоряем только разведку: меньше раундов Homer ↔ Nolan, но фактчек полный.

**Результат скана — в чат:** 0–3 кандидата, по каждому одна строка: тема · где выстрелила (канал, просмотры, возраст) · наш угол · вердикт «брать / не наша». Пусто — так и пишем, без натяжек.
